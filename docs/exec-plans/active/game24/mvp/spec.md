# Spec: game24-mvp

## 1. Solve

成年人在碎片时间里，从进入页点击「开始游戏」进入主页，正交选择**游戏模式**（1–10 普通或双面牌）与**玩法**（自由模式主线闯关 / 探索模式附加收集），再按主线进度关卡按序玩 24 点：点选合并牌面凑 24，合并链仅剩唯一最终结果时**自动判题**；运算有移动动画且可跳转回退，配合音效与计时；探索模式展示「已发现 X / Y」（Y 为题库 `solution_count`），找齐全部解法不是过关条件；自由模式过关后在结果页可分享给微信好友，好友进入**挑战关卡模式**（一种解法即完成，不修改好友主线进度与统计）；本地累计 `wins/attempts` 与主线进度——v1 纯前端、无登录。

交付范围：

- **页面流程**：进入页（v1 无登录）→「开始游戏」→ 主页（模式 + 玩法选择 + 开始）→ 做题页 → 自由模式过关结果页（分享入口）；分享落地 → 挑战做题页
- **游戏模式**（二选一，与玩法正交）：1–10 普通模式 / 双面牌模式（每张牌正反两面 1–10，可翻转；合并后锁定，回退可恢复）
- **玩法**（二选一，与模式正交）：**自由模式**（主线：任意一种正确解法即过关并推进下一关）/ **探索模式**（附加：展示「已发现 X / Y」，可随时结束探索，不推进主线、不计 win）
- **关卡成长曲线**（选题来自 `puzzles.jsonl`）：新手 1–20（解法 ≥ 5）、普通 21–80（2–4 种）、高手 81+（唯一解）；探索模式与自由模式同题同源（按当前主线关卡号）
- **核心玩法**：四张牌各用且仅用一次；`+ - × ÷`；括号由运算顺序自然形成；除法不要求整除；点选合并 + 移动动画 + 操作历史跳转回退；唯一最终结果时自动判题 + 文字反馈 + 「?」自愿看答案（`hintUsed`，自由模式结果页展示）
- **探索已定规则**：同算式不同合并路径视为同一种解法（归一化与 `tools/solve_all.py` 一致）；重复已发现解法不提示、计 attempts、X 不变；错误判题不增 X；「?」不增 X、不自动结束题目
- **体验**：音效、计时器
- **进度**：仅自由模式过关推进主线；本地 `ScoreRecord { wins, attempts }` 持久化（无重置入口）
- **分享**：结果页转发微信好友；好友进入挑战关卡模式（不带入局内半题进度；不写好友 wins/attempts/主线序号）
- **平台**：微信小程序纯前端；微信基础库最新稳定版；有 UI 参考稿

## 2. Do not solve

v1 明确不做：

- 微信登录 / openid
- 好友对战 / 同题 PK / 实时匹配
- 排行榜 / 云端榜单
- 分享局内半题进度（已发现 X/Y、计时、合并中间状态、`hintUsed`）
- 分享战绩卡片 / 成绩海报
- 主动分步提示（除「?」自愿看答案外）
- 跨关历史 / 错题本（当题内操作历史回退除外）
- 将找齐全部解法（X = Y）作为自由模式或主线过关条件
- 探索模式星形图标进度
- 统计 / 进度重置
- 后端 API / 云存储依赖核心玩法

v2+ 延后（Deferred）：

- 进入页升级为登录页
- 微信登录 + 云端榜单
- 好友对战
- 智能分步提示
- 历史 / 错题本

## 4. Frozen contracts

- `policy/layers.yaml` 中 `game24` 分层方向不可反转：`types → config → repo → service → runtime → ui`；跨切面仅 `providers/`（可 import `types`, `config`）
- `ScoreRecord` 字段：`{ wins: number; attempts: number }`；本地持久化，v1 无重置 API
- 页面层级：v1 进入页无登录；分享入口仅在自由模式过关结果页，不在主页/做题页常驻
- 游戏模式二选一：1–10 普通 / 双面牌（正交于玩法，非传统难度分级）
- 玩法二选一：**自由模式**（主线闯关）/ **探索模式**（附加收集）；找齐全部解法**不是**过关条件
- 主线推进：仅**自由模式**过关推进关卡序号；探索模式不推进、不计 win
- 探索进度：仅「已发现 X / Y」文本或等效组件；**禁止**星形图标；X 经归一化去重，规则与 `puzzles.jsonl` 离线生成器（`tools/solve_all.py`）一致；黄金测试验证
- 自动判题：合并链仅剩唯一最终结果时立即评估，无需单独提交按钮
- 「?」看答案：标记 `hintUsed` 并持久化至本关结束；自由模式结果页展示；不自动增加 X、不自动过关或结束题目
- 双面牌：合并消耗后锁定翻转；操作历史回退撤销合并后恢复可翻转与可见面
- 分享落地：好友进入**挑战关卡模式**（按自由模式规则：一种解法即完成）；题目为分享者当前关卡；**不**修改好友主线进度、`ScoreRecord.wins`、`ScoreRecord.attempts`；挑战过程不计入好友 attempts
- 关卡选题：数据来自 `puzzles.jsonl`；成长曲线：新手 1–20（`solution_count ≥ 5`）、普通 21–80（2–4）、高手 81+（唯一解）；普通模式 `cards` 全 ≤ 10
- 经典 24 点：四张各用一次；运算符仅 `+ - × ÷`；关卡题目保证有解
