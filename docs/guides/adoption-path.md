# Adoption path

See [Phodal: Rule → Spec → Harness](https://www.phodal.com/blog/from-rule-spec-to-harness-ai-coding-adoption-path/).

1. **Rule** — `policy/`, mechanical lint/tests (you are here after P1)
2. **Spec** — exec-plans + SDD
3. **Loop** — `docs/guides/loop.md`, progress artifacts
4. **Harness** — CI, review, GC (P2+)

Do not skip Rule and jump to multi-agent DAG.
